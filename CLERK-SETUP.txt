CLEAN WAVE - CLERK AUTHENTICATION SETUP

FILES
- Existing catalogue and cart are retained: app.js, style.css, cart.html and the three category pages.
- Clerk files added: clerk-config.js, clerk-auth.js, login.html, signup.html, account.html.

1. CREATE YOUR CLERK APPLICATION
- Open https://dashboard.clerk.com/ and create an application.
- Choose the sign-in methods you want (for example email + password, email verification, Google).
- In Clerk Dashboard > API Keys, copy the Publishable Key for your application.

2. ADD YOUR PUBLISHABLE KEY
- Open clerk-config.js.
- Replace YOUR_CLERK_PUBLISHABLE_KEY with your complete pk_test_... key while testing.
- Use pk_live_... only after configuring your production domain.
- NEVER put the Clerk Secret Key in any HTML or JavaScript file.

3. SET YOUR CLERK URLS / DOMAINS
- In Clerk Dashboard, add your local development origin (for example http://127.0.0.1:5500) and your production website domain as allowed origins/domains where requested.
- Configure the sign-in URL as /login.html and sign-up URL as /signup.html if your Clerk dashboard asks for them.
- Set the post sign-in and post sign-up destination to your site homepage (index.html).
- Use the same host consistently: do not mix localhost and 127.0.0.1 during testing.

4. RUN THE WEBSITE
- Keep all files in the same folder.
- Open the folder in VS Code.
- Start VS Code Live Server and open index.html through its http:// address. Do not use file://.
- Visit Login / Sign Up in the navigation, create a test user, and then sign in.

5. WHAT THE INTEGRATION DOES
- Clerk provides the sign-in and sign-up forms, email verification / configured identity providers, session management and user profile menu.
- The navigation shows Login / Sign Up when signed out and a Clerk user menu when signed in.
- WhatsApp checkout checks the Clerk sign-in state. If the customer is signed out, it redirects to login.html and returns them to the cart flow.
- The original product catalogue, product images, cart storage key (cleanWaveCart), +/- quantity controls, totals and WhatsApp ordering are retained.

IMPORTANT SECURITY LIMITATION
This is a static HTML/CSS/JavaScript website. The checkout check is a browser-side convenience check, not secure server-side authorization. Do not store private customer data, payment details, or confidential business data in this static site. For protected APIs, payment processing, or secure order storage, add a backend and verify Clerk session tokens on the server. WhatsApp orders are still sent to the business; this package does not create an orders database or payment gateway.
